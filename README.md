# IRONHOLLOW

Клон классического шутера от первого лица на чистых HTML, CSS и JavaScript.
Без движков, библиотек и сборщиков: откройте `index.html` в браузере (работает через `file://`).

Все текстуры, спрайты и звуки генерируются кодом. Игра не использует ассеты, названия, уровни
или дизайн персонажей id Software.

## Управление

| Действие | Клавиши |
|---|---|
| Движение / бег | WASD / Shift |
| Поворот | мышь (захват курсора) или стрелки |
| Огонь | ЛКМ или Ctrl |
| Оружие | 1–5, колесо мыши |
| Открыть дверь / секрет | E или Пробел |
| Карта | Tab |
| Пауза / меню | Esc (или потеря фокуса) |
| Быстрое сохранение / загрузка | F5 / F9 |
| Отладка (FPS, позиция, число спрайтов) | F3 |

Геймпад (по возможности): левый стик — движение, правый — поворот, правый курок — огонь.

## Структура

```
index.html, style.css
js/config.js      константы, настройки (localStorage)
js/input.js       клавиатура, мышь, геймпад
js/audio.js       синтез звука и музыки (Web Audio)
js/textures.js    процедурные текстуры стен, пола, потолка
js/sprites.js     процедурные спрайты: предметы, оружие, враги, эффекты
js/levels.js      уровни в виде ASCII-карт
js/map.js         загрузка уровня, коллизии, двери, секреты
js/items.js       предметы
js/enemies.js     враги: ИИ, зрение, шум, поиск пути
js/projectiles.js снаряды, взрывы, эффекты
js/player.js      игрок, оружие
js/hud.js         нижняя панель (лицо, патроны, здоровье)
js/renderer.js    raycasting, floor casting, спрайты, мини-карта
js/ui.js          меню, настройки, экраны смерти/итогов/победы
js/game.js        главный цикл, состояния, сохранения
```

Подробности устройства и известные ограничения — в описании коммитов и ответах по этапам.
